# Aston_team5_project
Учебный проект: сортировка кастомных объектов (фильмов).


## Заполнение списка фильмов

Все способы заполнения реализуют интерфейс `fill/DataSource` с одним методом `load(size)`. Метод возвращает список только корректных фильмов.

### Вручную — `ManualDataSource`
- Пользователь по очереди вводит название, жанр, год и продолжительность.
- При ошибке программа переспрашивает только то поле, где ошибка, а не весь фильм.

### Из файла — `FileDataSource`
- Одна строка — один фильм: `Название;Жанр;Год;Продолжительность`
- Строки, которые пустые или начинаются с `#`, пропускаются.
- Строка с ошибкой пропускается с сообщением `Строка N пропущена: <причина>`, загрузка продолжается.
- Если корректных фильмов меньше, чем запрошено, возвращается сколько есть.
- Примеры: `data/movies.txt` и `data/movies-with-errors.txt`.

### Случайно — `RandomDataSource`

- Название собирается из двух слов: `Тайна` + `океана`.
- Жанр — из готового списка, год — от 1950 до текущего, продолжительность — от 60 до 200 минут.
- Для тестов можно передать `new Random(42)`, тогда фильмы будут одинаковыми при каждом запуске.

### Запуск — `Main`

1. Выбрать способ: вручную / из файла / случайно.
2. Для файла указать путь (Enter — `data/movies.txt`).
3. Указать количество фильмов (от 1 до 100).


## Проверка данных — `validation/`

`MovieValidator` проверяет каждое поле фильма. При ошибке выбрасывается `ValidationException`.

| Поле | Правило |
| --- | --- |
| Название, жанр | не пустые, не длиннее 100 символов |
| Год | от 1888 до следующего года |
| Продолжительность | от 1 до 1200 минут |


## Как добавить новый способ заполнения

1. Создать класс, который `implements DataSource`.
2. Добавить пункт меню в `Main.chooseDataSource`.
