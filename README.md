# Aston_team5_project
Учебный проект: сортировка кастомных объектов (фильмов).


## Заполнение списка фильмов

Все способы заполнения реализуют интерфейс `fill/DataSource` с одним методом `load(size)`. Метод возвращает список только корректных фильмов.

### Вручную — `ManualDataSource`
- Пользователь по очереди вводит название, жанр, год и продолжительность.
- При ошибке программа переспрашивает только то поле, где ошибка, а не весь фильм.

### Из файла — `FileDataSource`
- Одна строка — один фильм: `Название;Жанр;Год;Продолжительность`
- Строки, которые пустые или начинаются с `#`, пропускаются.
- Строка с ошибкой пропускается с сообщением `Строка N пропущена: <причина>`, загрузка продолжается.
- Если корректных фильмов меньше, чем запрошено, возвращается сколько есть.
- Примеры: `data/movies.txt` и `data/movies-with-errors.txt`.

### Случайно — `RandomDataSource`

- Название собирается из двух слов: `Тайна` + `океана`.
- Жанр — из готового списка, год — от 1950 до текущего, продолжительность — от 60 до 200 минут.
- Для тестов можно передать `new Random(42)`, тогда фильмы будут одинаковыми при каждом запуске.

## Запуск — `Main`
`Main` запускает `Application`, который отвечает за основной цикл работы программы и взаимодействие пользователя с меню.

После запуска программа работает в цикле до тех пор, пока пользователь не выберет пункт выхода.

## Основное меню
Пользователю доступны следующие действия:

1. **Загрузить фильмы** — выбрать способ заполнения списка и добавить фильмы.
2. **Показать фильмы** — вывести загруженные фильмы на экран.
3. **Отсортировать фильмы** — выбрать алгоритм, поле и направление сортировки.
4. **Сохранить фильмы в файл** — дописать текущий список в `data/results.txt`.
5. **Отсортировать и сохранить** — отсортировать и сразу дописать результат в файл.
0. **Выход** — завершить работу программы.

Если список фильмов ещё не загружен, операции просмотра, сортировки и сохранения недоступны.

### Загрузка фильмов: 

1. Выбрать способ: вручную / из файла / случайно.
2. Для файла указать путь (Enter — `data/movies.txt`).
3. Указать количество фильмов (от 1 до 100).

## Проверка данных — `validation/`

`MovieValidator` проверяет каждое поле фильма. При ошибке выбрасывается `ValidationException`.

| Поле | Правило |
| --- | --- |
| Название, жанр | не пустые, не длиннее 100 символов |
| Год | от 1888 до следующего года |
| Продолжительность | от 1 до 1200 минут |


## Как добавить новый способ заполнения

1. Создать класс, который `implements DataSource`.
2. Добавить пункт меню в `Main.chooseDataSource`.

## Сортировка фильмов 
Для сортировки используется интерфейс `SortStrategy`, который позволяет выбирать алгоритм сортировки независимо от объекта и критерия сравнения.

### В приложении доступны следующие виды сортировки:
* `BubbleSortStrategy` — сортировка пузырьком;
* `MergeSortStrategy` — сортировка слиянием;
* `QuickSortStrategy` — быстрая сортировка.

`BubbleSortStrategy` и `MergeSortStrategy` реализованы в рамках данной части проекта.

Алгоритм сортировки получает список фильмов и `Comparator<Movie>`, поэтому один и тот же алгоритм можно использовать для разных критериев.

### Критерии сортировки
Фильмы можно сортировать по:
1. названию — `MovieTitleComparator`;
2. году выпуска — `MovieReleaseYearComparator`;
3. продолжительности — `MovieDurationComparator`;
4. жанру — `MovieGenreComparator`.

### Направление сортировки
После выбора критерия пользователь выбирает направление:
* по возрастанию;
* по убыванию.

Для обратного порядка используется `ReverseComparator`. Он получает исходный компаратор и меняет порядок сравнения его элементов.

Таким образом, алгоритм сортировки не зависит от направления сортировки: он всегда использует переданный ему `Comparator`.

### Как работает сортировка
Общая последовательность:

1. Пользователь выбирает алгоритм сортировки.
2. Выбирает критерий сортировки.
3. Выбирает направление — по возрастанию или по убыванию.
4. `Application` передаёт выбранный `Comparator` и список фильмов в `SortStrategy`.
5. Выбранный алгоритм сортирует список.
6. Отсортированный список можно посмотреть через пункт **«Показать фильмы»**.

## Сохранение результатов в файл (дополнительное задание 2)

За запись отвечает класс `fill/FileResultWriter` — симметричная пара к `FileDataSource`:
источник данных читает, писатель результатов сохраняет.

- Запись выполняется в **режиме добавления** (`StandardOpenOption.APPEND`):
  каждое новое сохранение дописывается в конец файла, предыдущие не затираются.
- Файл создаётся автоматически, если его нет (`StandardOpenOption.CREATE`).
- Каждая запись оформляется блоком: заголовок с описанием операции и временем
  сохранения, затем строки фильмов, затем пустая строка-разделитель.
- Формат строки фильма совпадает с форматом чтения:
  `Название;Жанр;Год;Продолжительность`, поэтому `data/results.txt`
  можно снова загрузить через `FileDataSource`.
- Кроме коллекций поддерживается запись произвольных найденных значений
  (метод `writeValues`) — задел для будущих дополнительных заданий.

Пример содержимого `data/results.txt`:

```text
=== Сортировка: QuickSortStrategy, поле: MovieReleaseYearComparator (2026-09-29 15:30:12) ===
Матрица;Фантастика;1999;136
Интерстеллар;Фантастика;2014;169

=== Текущий список (2 шт.) (2026-09-29 15:31:45) ===
Матрица;Фантастика;1999;136
Интерстеллар;Фантастика;2014;169
